# 立交固定入口（GitHub Pages）

入口页面读取当前公网网址，并在验证立交服务器身份后跳转。聊天、文件、验证码和游戏都继续留在电脑服务器。

`entry-config.json` 指定公开仓库、存放 `target.json` 的分支、身份协议和固定的服务器公钥。入口页面放在 `main` 分支，当前网址放在独立的 `live` 分支。网址变化时更新该文件，无需重复构建页面。公钥可以公开，身份私钥和仓库更新密钥只留在电脑。

`live` 分支的 `target.json` 格式：

```json
{"service":"lijiao-verified","protocol":"lijiao-entry-identity-v1","identityId":"与入口固定公钥对应的标识","target":"https://当前网址.cpolar.cn","updatedAt":0}
```

入口只接受 HTTPS cpolar 域名作为目标，不会仅凭图标或普通在线响应跳转。每次检查都会生成新的随机挑战值，请求目标的 `/api/server/identity`，并用入口中固定的 ECDSA P-256 公钥验证 SHA-256 签名。签名绑定身份标识、目标地址、挑战值和服务器签发时间；旧回复不能用于新的挑战。

身份接口请求不携带访问 Cookie，不跟随重定向。网址信息不完整、协议过旧、服务器离线、签名无效、目标或挑战不匹配时均保留等待页面。手机时钟无需与服务器完全一致。不支持安全身份验证的浏览器不会自动跳转。

更新后应刷新原来已打开的入口页面，以加载新的验证程序。实际网页访问与联调由用户进行。
